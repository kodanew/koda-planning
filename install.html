일정 안내 앱 설치 방법

폰 종류에 맞는 방법을 선택해 주세요.

방법 1앱 파일(APK)로 설치

⬇ KODA 앱 다운로드 (APK)
  1. 다운로드 버튼 누르기“이 파일은 기기를 손상시킬 수 있습니다”라는 안내가 나오면 확인 또는 그래도 다운로드를 눌러 주세요.
  2. 다운로드한 파일 열기화면 아래 알림이나 내 파일 → 다운로드에서 KODA.apk를 눌러 주세요.
  3. “출처를 알 수 없는 앱” 허용“보안상 이 출처의 앱을 설치할 수 없습니다”가 나오면 설정 → 이 출처 허용을 켜고, 뒤로 가기를 눌러 주세요.
  4. 설치 누르기설치를 누르세요. “Play 프로텍트” 안내가 나오면 더보기 → 그래도 설치를 눌러 주세요.
  5. 열기설치가 끝나면 열기를 누르거나 홈 화면의 KODA 아이콘을 눌러 주세요.
위 경고는 Play 스토어가 아닌 곳에서 받은 앱이면 모든 앱에 나오는 안드로이드 기본 안내입니다. 한국디벨로퍼협회에서 직접 배포하는 앱이니 안심하셔도 됩니다. 설치 후 “출처 허용”은 다시 꺼두셔도 앱 사용에는 지장이 없습니다.

방법 2더 간단하게: 크롬에서 바로 설치

  1. 크롬으로 접속크롬에서 kodanew.github.io/koda-planning을 열어 주세요.
  2. 앱설치화면의 앱설치 버튼, 또는 크롬 메뉴(⋮) → 앱 설치 / 홈 화면에 추가를 눌러 주세요.
이 방법은 경고 없이 바로 설치됩니다.

아이폰홈 화면에 추가해서 앱처럼 사용

아이폰은 APK 파일을 설치할 수 없습니다. 아래 방법으로 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.
  1. Safari로 접속Safari에서 kodanew.github.io/koda-planning을 열어 주세요. 카카오톡 안에서 링크를 누르면 Safari로 열리지 않을 수 있으니, 링크를 길게 눌러 Safari로 열기를 선택해 주세요.
  2. 공유 버튼 누르기화면 아래(또는 위) 가운데의 ⬆ 공유 버튼을 눌러 주세요.
  3. 홈 화면에 추가메뉴를 위로 올려 홈 화면에 추가를 누르고, 오른쪽 위 추가를 눌러 주세요.
  4. 홈 화면 아이콘으로 실행홈 화면에 생긴 KODA 아이콘을 누르면 주소창 없이 앱처럼 열립니다.
iOS 16.4 이상은 크롬에서도 같은 방법(공유 → 홈 화면에 추가)으로 추가할 수 있습니다.
